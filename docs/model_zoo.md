# Model and benchmark status

This maintained fork does not publish a current model zoo, checkpoint registry, or supported OBB benchmark table. The former page inherited upstream YOLOX COCO/HBB numbers and download references; those values are not measurements of this fork and are intentionally not presented as current guarantees.

Concrete training runs, datasets, checkpoints, export variants, evaluation results, and artifact provenance belong in [`card-detector-training`](https://github.com/shapovalovei/card-detector-training). A local test pass proves selected framework correctness; it does not select or qualify a model.

For framework behavior, use the [maintainer guide](maintainer_guide.md) and the current source/tests. For mobile or device results, use [`react-native-scanner-sdk`](https://github.com/shapovalovei/react-native-scanner-sdk) and its target-specific qualification evidence.
